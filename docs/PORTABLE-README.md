# Codex Relay Windows 便携版

1. 将 ZIP 完整解压到当前用户可写的目录，双击 `启动中转站.cmd`。
2. 浏览器自动打开管理页面，默认地址为 `http://127.0.0.1:4317/`。
3. 本机配置或 ChatGPT 账户需要官方 Codex。在“系统设置 → 环境与诊断 → 原生运行环境”选择自动模式时，保持官方桌面运行并检测安装；选择独立模式时，填写中转站所在机器上 `codex.exe` 的绝对路径并点击“校验并保存路径”，无需桌面。
4. 添加并验证账户或本机配置实例、启用模型路由，然后创建对应分组的 API Key。客户端使用页面提供的 Base URL、Key 和模型 ID。

适用于 Windows x64；包内不包含官方桌面客户端或账户。程序未作发行者代码签名。

如需前台运行，在包目录的 PowerShell 执行 `./codex-relay.exe serve`，按 Ctrl+C 退出；有独立网络配置时追加 `--network-config data/network.json`。不要与后台实例同时启动。需要额外管理令牌时追加 `--require-admin-token`。

仅使用 API Key 直连账户时，无需安装官方桌面客户端。

## 修改端口

编辑根目录 `relay.config.json`，例如：

```json
{
  "port": 8080
}
```

保存后先在管理页面停止中转站，再双击启动。管理地址变为 `http://127.0.0.1:8080/`，客户端 Base URL 为 `http://127.0.0.1:8080/v1`。默认端口为 4317。

## 远程访问与独立 API 端口

首次启动默认允许外部访问，已有访问设置保持不变。其他电脑可使用服务电脑的实际 IP 或域名和配置的端口。在设置中可配置后台密码或关闭外部访问。客户端 API 始终需要 API Key。外部访问还需自行配置防火墙和路由器。

需要仅提供 API 的独立端口时，创建 `data/network.json`：

```json
{
  "listeners": [{
    "listen": "0.0.0.0:4318",
    "baseUrls": ["http://192.168.1.10:4318/v1"],
    "allowedOrigins": []
  }]
}
```

将示例 IP 替换为服务电脑的实际地址，重启后生效；独立端口不能与主端口相同。双击启动器会自动加载该文件。完整 HTTPS、反向代理及客户端调用说明保留在源码项目的 `docs/` 和 `examples/`，精简便携包不附带这些目录。

## 停止、更新与数据

关闭浏览器不会停止服务；请点击管理台侧栏底部版本信息旁的电源图标，并确认停止中转站。手机端先展开导航菜单。重复双击启动器会复用本目录正在运行的服务。

首次启动会生成 `data/`（账户、密钥、配置、统计）和 `.cache/`（本机安装记录、日志）。不要将这两个目录分享给他人。更新前停止服务并备份它们，再替换程序、启动器和 `web/`，保留自己的 `relay.config.json` 和 `.cache/`。项目尚未正式发布，存储格式会随开发调整。需要重新初始化测试数据时，在服务停止后将 `data/accounts` 移出运行目录备份，再启动并重新配置账户和密钥；程序不会自动清空已有数据。官方桌面升级后，在管理页面重新检测原生安装。

便携包只保留程序、界面、启动入口、端口配置、此说明、`manifest.json` 文件校验清单和 `third-party/` 许可原文。无需安装开发工具。Windows 的 `scripts/Open-Relay.ps1` 是启动入口的必要依赖，请保留；macOS 无需 `scripts/`。第三方许可在 `third-party/LICENSES.txt`，来源和校验信息在 `third-party/dependencies.json`。
