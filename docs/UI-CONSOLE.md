# 管理界面与验证

管理台按账户接入流程组织，默认进入账户管理。页面使用 React + Vite，调用 Rust 管理接口。用量统计、账户订阅与额度、账户亲和设置的行为分别见 [运行管理](OPERATIONS.md)、[账户管理](ACCOUNT-MANAGEMENT.md) 和 [Responses 接入](RESPONSES.md)。

## 页面入口

| 页面 | URL | 功能 |
| --- | --- | --- |
| 账户管理 | `?view=accounts`，或直接打开根路径 | 搜索、状态筛选、分页、所属分组、接入开关、实例操作 |
| 账户详情 | `?view=accounts&account=<id>&section=login` | 登录与凭据；`section=access` 为接入与调度；`section=advanced` 为高级能力 |
| 分组管理 | `?view=groups` | 成员、容量、分组编辑、启用状态、调度检查 |
| 客户端接入 | `?view=keys` | API 密钥；`tab=guide` 为接入地址、cURL/Python 示例和 WebSocket 说明 |
| 请求监控 | `?view=requests` | 筛选请求记录和查看详情；`tab=queue` 为等待队列和取消等待 |
| 用量统计 | `?view=statistics` | 模型请求与 Token 概览、缓存命中率、趋势、账户／密钥／模型排行、实时调度容量、带筛选跳转请求记录 |
| 系统设置 | `?view=settings` | 连接与调度，包括账户亲和时间；`tab=security` 为访问安全；`tab=diagnostics` 为环境与诊断 |

环境与诊断使用 `?view=settings&tab=diagnostics`，账户登录与凭据使用 `?view=accounts&account=<id>&section=login`。导航和文档统一使用当前入口。

## 实现约定

- `App` 组合页面，`ConsoleShell` 管理侧栏和移动抽屉，`useConsoleSession` 管理共享登录会话和概览轮询。
- 停止服务入口位于侧栏底部版本信息旁，使用带提示及无障碍名称“停止中转站”的电源图标，所有页面均可访问；手机端先展开导航菜单。确认弹窗挂载到页面根部，默认聚焦“继续运行”；取消或 Escape 返回触发按钮，只有确认后才调用 `/api/service/stop`。退出期间禁止重复提交。“停止桌面调试”只断开调试连接并回收所属后端，保留桌面窗口；侧栏电源图标停止整个中转站。
- “连接与调度”将服务总并发、等待队列、账户亲和和请求记录保存时长整合在同一面板，各区独立保存并保留编辑草稿；并发与排队显示当前占用及进度条。宽屏说明与表单并排，窄屏纵向排列；规则说明默认折叠，不再包含独立的停止服务卡片。侧栏与连接设置的样式分别位于 `console-shell.css`、`connection-settings.css`。
- `navigation` 使用查询参数记录筛选、分页和标签。搜索替换当前历史项；分页和页面导航添加历史项。账户详情沿用列表筛选参数，返回时定位原账户。
- 轮询保留现有数据和编辑组件。调度、代理和访问安全表单不使用远端配置值作为 React key；只有用户明确还原表单才重建对应编辑器。
- 颜色统一使用语义变量；正文和代码分别使用本机界面字体和等宽字体，不加载外部字体。桌面侧栏宽度 216px；760px 以下使用带 Escape 关闭、焦点约束的抽屉。
- 窄屏密钥和请求表格采用纵向布局，复制、编辑和请求详情直接可达。横向滚动区域建立定位上下文，防止隐藏的辅助标签逃逸到页面外。
- 请求表将端点、上游协议、接入协议和 User-Agent 合并到“连接 / 客户端”列，详情仍可分别查看这些字段；原生 app-server 的内部上游协议显示“原生”，未采集值保持未知。账户列表直接显示实例实际使用的客户端名称和版本，不附加 `clientInfo` 字段名前缀；身份详情仍保留原始字段。
- 用量统计与请求记录默认查询浏览器本地时区的今天，可按开始、结束日期筛选。日期框不显示上方字段文字，保留辅助技术可读的标签。日期写入 URL 的 `startDate`、`endDate`；API 使用闭区间 Unix 毫秒 `from`、`to`，与 `hours` 参数互斥；未提供范围的 API 调用使用过去 24 小时。自然日边界兼容夏令时的 23/25 小时日期。
- 用量统计和请求记录均每 30 秒自动更新；两处均提供刷新图标，不增加自动/手动模式切换。
- 手动和后台额度刷新不写入请求记录，也不计入请求统计。额度重置、连接测试和模型请求仍保留记录。
- 账户所属分组单独成列，分组页移除调度流程说明。密钥固定单行，超长时省略中间，末尾 8 字符与完整复制保持可用。
- 账户详情按操作归属拆分：本机配置检测、OAuth 登录和凭据导入仅在“登录与凭据”；接入开关、连接测试、API Key 入口、所属分组与调度仅在“接入与调度”。两个标签保留各自未提交的表单与检测结果。“接入与调度”的代理、时区、启用和调度采用统一设置网格，宽屏等宽分区，窄屏上下排列，内容沿工作区边缘对齐；连接测试与检测说明默认折叠。
- 列表展示一个有可见标签的“启用账户”开关；实例运行只展示状态。操作区提供测试对话、展开详情、账户设置和删除入口，配有悬停提示与无障碍名称；手动启动、停止和重启统一位于详情“高级能力 → 实例维护”。详情页移除“参与调度”复选框，使用同一个账户启用开关。关闭先拒绝新请求，当前任务完成后停止实例；手动中断任务或删除账户需要确认。弹窗关闭后焦点返回触发图标。
- 账户启停请求提交后，列表与详情立即显示“启用中…”或“停用中…”，开关禁用并标记忙碌；成功刷新服务端状态，失败保留原开关值并提示错误。订阅首次查询和重试状态随概览轮询更新；有效额度窗口剩余低于 10% 显示橙色、耗尽显示红色，未知或已结束窗口使用中性色。
- 用量统计将模型请求、总 Token 和缓存命中率及各自的小趋势放在顶部，提供今天、近 7 天、近 30 天快捷日期和可折叠筛选；输入、输出、缓存输入共用下方趋势图，支持指针、键盘和时段表格。排行通过 `usageBy=account|key|model` 切换，默认密钥；运行质量默认折叠。模型统计与全局实时容量的口径见 [用量统计页面](OPERATIONS.md#用量统计页面)。请求记录默认每页 20 条，可切换 50 或 100 条，选择保存在 URL 的 `pageSize`。
- 访问安全首次设置密码时输入一次非空新密码；新密码字段明文可见，不设 8–128 字符限制，也不要求确认输入。已有密码时，新密码留空表示保留，当前密码与登录密码仍遮蔽显示；接口请求体大小限制继续生效，见 [网络接入](NETWORK-ACCESS.md)。
- 原生登录、凭据导入、队列取消与停止服务沿用现有接口。账户代理通过 `/api/accounts/{id}/proxy` 独立设置，默认自动；保存后立即自动重启运行中的账户实例（中断此账户当前请求和登录），页面显示生效状态和重试入口。客户端工具默认可用，图片、搜索和生图默认自动接入，账户高级能力可明确关闭；目录过期不锁定开关。耗用模型额度的能力诊断仅由用户主动触发，诊断不改变开关。
- “环境与诊断”采用检查主区和调试工具侧区：主区放置原生运行环境、读取提供方、桌面检查及桌面连接协议验证；侧区放置请求原文调试、桌面连接调试和检查记录。宽屏并排，窄屏顺序排列；样式集中在 `diagnostics-settings.css`。各项检查按需触发，展示运行状态、错误和对应结果；新检查运行时仍可查看上次结果，失败时展开明细，检查记录按当前服务运行期间的时间倒序显示。
- 原生安装支持自动检测桌面和独立 Codex 路径；独立模式禁用不适用的桌面诊断及桌面调试。请求原文调试默认关闭，开关支持键盘操作，保存后保留焦点；关闭或重启会清空原文并保留统计。采集范围及清理规则见 [请求原文调试](DEVELOPMENT-CHECKS.md#请求原文调试)。

## 操作提示

保存、复制、启停、删除、额度刷新等主动操作的成功、失败或说明统一通过页面顶部居中的浮动提示展示，不挤占页面布局，不自动抢走焦点。提示使用成功、错误、信息三种语义，支持手动关闭；成功和信息提示默认 5 秒后消失，错误提示默认 8 秒后消失，鼠标悬停或键盘焦点位于提示内时暂停计时。

根入口通过 `ToastProvider` 管理提示，各操作组件调用 `useToast()`，样式位于 `toast.css`。同时最多显示 4 条，相同内容和类型的提示再次触发时替换旧提示并重新计时。提示通过 Popover 顶层展示；原生模态弹窗打开时挂载到当前弹窗内，保持可见且可关闭；操作关闭弹窗或删除账户行后，提示仍可继续显示。错误内容使用 `role="alert"`，其他内容使用 `role="status"`；支持深浅主题、窄屏换行和减少动画偏好。

需要持续查看或继续操作的信息仍在原位置展示，包括服务连接失败与重试、存储异常、退出状态、字段校验、本机配置检测结果、OAuth 授权链接与设备码，以及批量操作的逐项结果。操作失败不会清空未提交的编辑内容。新增主动操作反馈应复用 `useToast()`，避免另建局部成功或错误横幅。

## 自动化验证

前端日常修改运行快速检查，再按涉及的页面选择 Playwright 文件，例如：

```powershell
pnpm check:quick:web
pnpm test:web service-controls.spec.ts request-transports.spec.ts
```

Playwright 使用独立 Vite 端口 5174 和独立浏览器测试进程，本地默认 Chrome，CI 使用配套 Chromium；并发按内存和 CPU 限制。端口占用时可通过 `BRIDGE_TEST_WEB_PORT` 选择其他独立端口。所有 `/api` 请求由本地 fixture 接管，未匹配接口返回错误，不会转发到真实服务。使用 `pnpm --filter @codex-relay/console exec playwright test --list` 查看当前清单；列出测试不代表执行通过。

回归覆盖账户启停与待处理状态、OAuth 与凭据、账户迁移、订阅自动更新、额度窗口与颜色、调度和账户亲和设置、密钥编辑、取消等待、请求详情、日期与筛选、模型用量与缓存趋势、排行诊断、实时容量、登录与密码设置、断线恢复和浮动提示。管理接口字段变化另须运行 `pnpm test:contracts`，模拟浏览器响应不能代替真实 Rust 响应校验。检查入口与范围见 [开发检查](DEVELOPMENT-CHECKS.md)。

侧栏停止入口及确认焦点由 `service-controls.spec.ts` 覆盖桌面与手机；连接设置、记录保存时长及请求连接信息分别查看 `global-concurrency.spec.ts`、`key-transfer-retention.spec.ts` 和 `request-transports.spec.ts`。这些用例使用模拟 API，不会停止正在运行的真实服务。

环境与诊断的布局、保存结果、失败状态、运行中结果保留、深浅主题和键盘焦点查看 `diagnostics-layout.spec.ts`；安装设置及原文开关分别查看 `installation-settings.spec.ts`、`request-debug.spec.ts`。按改动选择文件，例如 `pnpm test:web diagnostics-layout.spec.ts installation-settings.spec.ts request-debug.spec.ts`；列出覆盖范围不代表已执行验证。

`web/tests/notifications.spec.ts` 包含 5 项提示专项测试：布局与焦点保持、弹窗内错误可关闭且保留草稿、删除账户并关闭弹窗后提示保留、自动消失与悬停暂停及重复提示、手机深色主题下的视口边界。可单独运行 `pnpm --filter @codex-relay/console test tests/notifications.spec.ts`。

布局回归覆盖 375、768、1024、1440、2560px 及深浅主题，同时检查账户操作、删除与密钥弹窗边界和手机抽屉键盘操作。修改布局或配色后应重新执行相关回归；历史截图与配色检查不证明当前改动已验证。截图和失败 trace 保存于忽略目录 `.cache/ui-tests/`。

读取已经运行的真实管理服务：

```powershell
pnpm --filter @codex-relay/console test:readonly http://127.0.0.1:4317
```

此脚本逐页检查 1440px 和 375px 布局，并拦截所有非 GET 管理请求。只保存账户和统计截图，避免截取真实密钥。需要管理台处于可读取状态；本机检查不会替代真实上游推理验收。真实账户、分组、密钥、设置和运行进程均不通过此脚本修改。

管理接口字段变化需要同时更新后端程序和 `web/dist`。日期筛选、统计用量与请求详情的后端回归可运行 `node scripts/cargo-with-memory.mjs test --locked --test statistics_dates --test statistics_usage --test operations --test cache_usage --test request_details`；前端可运行 `pnpm test:web statistics-usage.spec.ts usage-diagnostics.spec.ts`。实际执行的结果应在交付时单独说明。
